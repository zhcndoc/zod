> **注意** — Ecosystem 部分聚焦于支持 Zod 4 的库。如果你的库支持 Zod 4，请提交 PR 将其添加进来。对于支持 Zod 3 的库，请参阅 [v3.zod.dev](https://v3.zod.dev/?id=ecosystem)。

基于 Zod 构建或原生支持 Zod 的工具正在不断增加！如果你基于 Zod 开发了工具或库，请通过 [Twitter](https://x.com/colinhacks) 告诉我，或在 [讨论区](https://github.com/colinhacks/zod/discussions) 发起讨论。我会将其添加到下面，并在推特上分享。
